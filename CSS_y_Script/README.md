# Sistema de Préstamos - Inversiones Génesis

Sistema web desarrollado con Flask para la gestión de préstamos y clientes.

## Tecnologías utilizadas

- Python
- Flask
- Flask-SQLAlchemy
- Flask-Login
- Bootstrap
- HTML
- CSS
- JavaScript

## Funcionalidades

- Inicio de sesión
- Gestión de usuarios
- Gestión de clientes
- Gestión de préstamos
- Ruta de hoy
- Panel principal
- Control de acceso
